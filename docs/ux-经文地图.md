# 经文地图（按节出图）

地图是读经的一种展示：长按一节，看出它在讲哪里。不是独立 GIS，也不靠模型画像素图。

## 现在的问题

- 「地图」藏在更多里，且没有命中别名就隐藏
- 匹配整章正文，不是这一节
- 只有约 15 个点，对不上「本节在讲什么地方」
- 模型不该直接生成一张图文件（难校验、易胡画）

## 定稿交互

1. 长按经文，第一层就有 **地图**（始终显示）。
2. 点地图：先关菜单，立刻打开地图 sheet，标题为「本节地理」。
3. **先本地**：用词表扫本节及前后各 2 节。有点就钉上，有路线就连线。
4. **再助手**（有 Key 且设置开着）：把经文 + 词表 id 交给模型，只要 JSON（`ids` / `route` / `extras` / `why`）。用同一套 SVG 画出来。失败则保留本地结果。
5. 本节没有地名：提示「本节没有写出地名」，可点「用助手分析背景」。约翰福音 3 章可推断尼哥底母在耶路撒冷。
6. 词表外的地点（罗马、埃及、哥林多）只进「图外」列表，不假装画在迦南框里。
7. 同一译本同一节的分析结果缓存，避免每次都打模型。
8. 有命中时把相关点放大到画面中心，其它点变淡。

## 模型产出（不是图片）

```json
{"ids":["jerusalem"],"route":[],"extras":[{"name":"罗马","note":"图外"}],"why":"本节背景在耶路撒冷"}
```

`ids` 必须来自词表。渲染仍用现有示意坐标。模型负责**选点、连线、说明**，不负责经纬度。

## 设置

阅读设置：`经文地图用助手补充`（默认开；没 Key 则只有本地）。

## 不做

- 不让模型生成 SVG/PNG 当地图底图
- 不改顶栏读本章
- 不把地图做成第五个底栏
- 不把推断当成精确考古
