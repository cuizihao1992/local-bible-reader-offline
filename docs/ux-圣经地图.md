# 圣经地图 UX（三轮迭代后定稿）

来源：`C:\Users\Administrator\XiaomiMiMoProjects\2026-09-23\app` 示意地图原型。  
阅读器约束：经文只从本机译本取；阅读页是唯一全屏；底栏不增加第五项。

## 综合分析

原型是离线 SVG 示意图（15 地点、5 旅程），不是经纬度地图。价值是「读到地名时能看见在哪」。不能整页替换阅读器，也不能用它写死的经文当正文。

---

## 第 1 轮

**方案：** 「我的」加第五个 Tab「地图」，里面塞原型的地图 / 旅程 / 地名。

**评估：** 「我的」已有标注 / 经文库 / 资源 / 更新，再加 Tab 会挤；地图放在 sheet 的一层 Tab 里高度不够缩放；和底栏抢心智。

**修改：** 不在「我的」加第五 Tab。

---

## 第 2 轮

**方案：** 「我的 · 标注」放一张「圣经地图」卡片，点开独立全高 `mapSheet`。Sheet 内用 地图 / 旅程 / 地名 三个子页。经文菜单「更多」加地图。

**评估：** 入口可发现，地图够大。缺读经中的跳转；保罗线把大数钉在迦南图上会误导。

**修改：** 本章若命中地名，阅读区出「本章地点」一行（最多 3 个 + 更多）。图外地点（大数、安提阿）只出现在列表/旅程，不画在迦南框里。

---

## 第 3 轮（定稿）

**方案：**

1. **入口**
   - 「我的 · 标注」卡片「圣经地图 · 示意」
   - 阅读区「本章地点」chips（有匹配才出现）
   - 经文菜单第一层「地图」（始终显示；见 `docs/ux-经文地图.md`）
2. **地图 sheet（全高，仍是 sheet）**
   - 子页：地图 | 旅程 | 地名
   - 时代筛选：全部 / 族长 / 出埃及 / 王国 / 耶稣 / 保罗
   - 图例：确定 / 推定 / 陆路 / 海路
   - 角标：「示意，不是精确比例」
3. **地点详情（sheet 内第二层）**
   - 今名、确定/推定、简介
   - 相关经文用**当前译本**，点引用跳章
   - 相关旅程
4. **旅程**
   - 站点列表；图外站点标注「图外」
   - 「在地图显示路线」回到地图子页画线
5. **返回**
   - 地点详情 → 地图 sheet → 关掉 sheet（若从阅读进来则 peek 回阅读）
6. **不做**
   - 第五底栏、在线瓦片、克隆 TTS、把《简明圣经史地图解》打进包、Quiz/导游

**评估：** 读经主路径不被抢；离线；经文来源正确；示意边界写清。通过，进入开发。
